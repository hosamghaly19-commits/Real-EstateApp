# تطبيق العقارات المحلي — المشروع كامل في مكان واحد

```
app/        تطبيق Flutter  (31 ملف Dart، ~6530 سطر، 7 شاشات)
backend/    API (Express + TypeScript) + قاعدة البيانات (Prisma / Neon PostgreSQL)  (~1545 سطر)
.github/    اختبار تلقائي للتطبيق على GitHub (Flutter CI)
```

## الحالة بصراحة

**ده مش تطبيق جاهز للإطلاق لسه.** ده مشروع شغّال جزئياً، وده التفصيل:

| الجزء | الحالة |
|---|---|
| **شاشات التطبيق** (Splash، Onboarding، الرئيسية، التفاصيل، المعاينة، طلبات المعاينة، إضافة عقار، لوحة المكتب/المطور) | ✅ مبنية — ⚠️ **ماتشغّلتش على Flutter ولا مرة** (مفيش Flutter في بيئتي) |
| **الباك إند: العقارات والمعاينات** (الدفع، القبول/الرفض/الموعد البديل، الاسترداد، انتهاء المهلة) | ✅ **متجرّب فعلياً**: 25 اختبار تكامل على PostgreSQL حقيقي |
| **قاعدة البيانات** (13 جدول + قيود) | ✅ متجرّبة على PostgreSQL 16 محلي — ❌ ما اتطبّقتش على Neon |
| **ربط التطبيق بالـ API** | 🟡 **العقارات فقط** (الرئيسية، التفاصيل، الإضافة، إعلاناتي) — ⚠️ ماتجرّبش على جهاز |
| **ربط المعاينات بالـ API** | ❌ لسه — شاشات المعاينات بتشتغل ببيانات تجريبية |
| تسجيل الدخول (Auth) | ❌ مفيش. بيستخدم هيدر تجريبي `x-demo-phone` |
| بوابة الدفع الحقيقية | ❌ مفيش. الدفع والاسترداد **محاكاة** بتنجح دايماً |
| رفع الصور | ❌ مفيش. الإضافة بتستخدم صور عيّنة |
| النشر (Neon + Render) | ❌ ما اتنشرش. `render.yaml` موجود بس ماجرّبتوش |
| المفضلة، الإشعارات، الدردشة/الاتصال، بروفايل المعلن، المحفظة، صفحة المشاريع | ❌ إما شكل فقط أو مش موجود |
| الإطلاق على المتاجر (أيقونة، توقيع، سياسة خصوصية، مراجعة قانونية للرسوم) | ❌ |

## الطريق لتطبيق كامل (بالترتيب)

1. **تشغيل التطبيق وتصحيح الأخطاء** — أهم خطوة دلوقتي (طرق التشغيل تحت).
2. **ربط المعاينات** بالـ API (على قواعد السياسة اللي في الباك إند).
3. **الـ Auth الحقيقي** (OTP ولا Password — محتاج قرارك).
4. **نشر Neon + Render** وتشغيل أول migration.
5. **رفع الصور** (تخزين + image_picker).
6. **بوابة الدفع** الحقيقية والاسترداد الفعلي (محتاج اختيار المزوّد).
7. باقي المميزات: المفضلة، الإشعارات، الاتصال، بروفايل المعلن، المحفظة، المشاريع.
8. تجهيز الإطلاق: أيقونة وتوقيع وسياسة خصوصية وشروط، ومراجعة قانونية لرسوم المعاينة والاسترداد.

## تجربة التطبيق

### أ) بدون باك إند (أسرع طريقة تشوف الشاشات)
```bash
cd app
flutter create .          # بيولّد فولدرات الأندرويد/iOS/ويب حوالين الكود (لو فيه سؤال عن الكتابة فوق: لا)
flutter pub get
flutter run               # بيانات تجريبية في الذاكرة
```
> بعد `flutter create .` امسح `test/widget_test.dart` (ملف المثال اللي بيولّده) لو ظهر.

### ب) مع الباك إند الحقيقي
```bash
cd backend                # شوف backend/README.md (Neon أو Postgres محلي)
cp .env.example .env      # حط الـ connection strings
npm install
npx prisma migrate dev --name init --create-only
cat prisma/sql/constraints.sql >> prisma/migrations/*_init/migration.sql
npx prisma migrate dev
npm run db:seed && npm run dev      # http://localhost:3000

cd ../app
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000
```
تفاصيل العناوين لكل جهاز: `app/README_API.md`.

### ج) من غير ما تثبّت Flutter: GitHub Actions
ارفع **كل محتوى المشروع ده** (بما فيه فولدر `.github`) على repo في GitHub. هيشغّل أوتوماتيك:
`flutter analyze` ← `flutter test` (39 اختبار) ← بناء نسخة ويب، وينشرها على GitHub Pages لو فعّلتها
(*Settings ← Pages ← Source: GitHub Actions*، ومحتاج repo عام). لو أحمر: افتح الـ step اللي فشل وابعتلي الأخطاء.
