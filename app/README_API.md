# تشغيل التطبيق مع الـ API

التطبيق عنده وضعين:

| الوضع | إزاي يشتغل | الاستخدام |
|---|---|---|
| **تجريبي** (الافتراضي) | `flutter run` | بيانات في الذاكرة، من غير سيرفر. مناسب للتصميم والـ CI |
| **API** | `flutter run --dart-define=API_BASE_URL=<العنوان>` | بيكلّم الباك إند الحقيقي |

## 1) شغّل الباك إند
في فولدر `real_estate_backend` (شوف README بتاعه): `npm run dev` → `http://localhost:3000`.

## 2) شغّل التطبيق بالعنوان المناسب

| بتشغّل على | العنوان |
|---|---|
| Chrome / ويب | `--dart-define=API_BASE_URL=http://localhost:3000` |
| محاكي Android | `--dart-define=API_BASE_URL=http://10.0.2.2:3000` |
| موبايل حقيقي (نفس الشبكة) | `--dart-define=API_BASE_URL=http://<IP-الكمبيوتر>:3000` |
| سيرفر على Render | `--dart-define=API_BASE_URL=https://<اسم-الخدمة>.onrender.com` |

أمثلة: `flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000`

**ملاحظات (راجعها عند أول تشغيل على الأجهزة):**
- **Android:** لازم صلاحية الإنترنت في `android/app/src/main/AndroidManifest.xml`:
  `<uses-permission android:name="android.permission.INTERNET"/>`
  (بتتضاف تلقائياً في الـ debug بس مش في الـ release).
  وللاتصال بـ `http://` (مش https) في التطوير ضيف `android:usesCleartextTraffic="true"` على وسم `<application>`.
- **iOS:** الاتصال بـ `http://` بيتمنع افتراضياً (ATS). استخدم https أو محاكي/ويب في التطوير.
- **Render (الخطة المجانية):** أول طلب بعد فترة خمول ممكن ياخد 30–60 ثانية، والعميل عنده مهلة 15 ثانية، فممكن تظهر "السيرفر اتأخر" مرة أولى. جرّب تاني.

## اللي بقى حقيقي وفي الوضع الافتراضي لسه تجريبي

| الجزء | وضع API |
|---|---|
| الرئيسية: بحث وفلترة (بيع/إيجار، النوع، الحي، السعر، التشطيب، الدفع، النص) | ✅ من السيرفر |
| الأحياء | ✅ من السيرفر |
| تفاصيل العقار (كل الصور، الوصف، المميزات) | ✅ |
| إضافة عقار | ✅ بيتحفظ في الـ DB |
| إعلاناتي + المشاهدات في لوحة الحساب | ✅ |
| **المعاينات** (الطلب، الدفع، القبول/الرفض، الاسترداد) | ⏳ لسه تجريبي — الخطوة الجاية |
| مشاريع المطورين، المفضلة، الإشعارات | ⏳ تجريبي |

⚠️ في وضع API، طلبات المعاينة الظاهرة (الشاشة والداشبورد) **بيانات تجريبية** لعقارات مش موجودة في السيرفر.
فصفحة العقار اللي بتتفتح منها بتفضل تعرض البيانات المحلية (من غير ما تفشل).

## الدخول (تجريبي)
مفيش تسجيل دخول لسه. كل طلب بيبعت هيدر `x-demo-phone`، والسيرفر بيعتبرك صاحب الرقم ده:
- زرار "عرض كمكتب / كمطور" في لوحة الحساب بيبدّل الهوية: `01000000001` (مكتب الأمان) ↔ `01000000003` (مطور الأفق).
- الأرقام دي من الـ seed، وهتتشال لما نبني الـ Auth الحقيقي.

## الاختبارات
`flutter test` — بتشمل اختبارات للعميل والتحويلات (`test/api_*_test.dart`, `test/property_repository_test.dart`).
الملفات في `test/fixtures/` **ردود حقيقية اتسحبت من الـ API** (لو غيّرنا شكل الرد في الباك إند لازم نسحبها تاني).
